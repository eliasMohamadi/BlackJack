# 🃏 Blackjack

A graphical Blackjack game built with Python and Pygame.

This project was originally developed as part of a freshman-year computer science game competition. I worked with a team to create a playable Blackjack game with a graphical interface, interactive buttons, custom card graphics, sound effects, and game logic.

## 🎮 Features

- Interactive graphical Blackjack game
- Card deck and Blackjack game logic
- Hit and Stand functionality
- Betting interface
- Min/Max betting controls
- Interactive UI buttons
- Custom playing-card graphics
- Background music and sound effects
- Help and Credits screens
- Custom game splash/title screens

## 🛠️ Technologies

- **Python**
- **Pygame**
- **Git / GitHub**
