# ♠️ Blackjack

A graphical Blackjack game built from scratch using Python and Pygame.

🏆 **Winner of a Kennesaw State University Computer Science Game Competition**

## 🎮 About

This project is a fully playable Blackjack game developed with Python and Pygame. The game implements traditional Blackjack gameplay, including betting, hitting, standing, dealer logic, and card handling.

The project was built from scratch, including the game's artwork and visual assets.

## ✨ Features

- ♠️ Full Blackjack gameplay
- 💰 Betting and gambling mechanics
- 🃏 Player and dealer card logic
- 🎯 Hit and stand functionality
- 🃏 Automatic card drawing and hand evaluation
- 🔊 Custom sound effects and background music
- 💾 Persistent game data
- 🎨 Custom graphical user interface
- 🖥️ Interactive menus and buttons

## 🎨 Original Artwork

Every visual asset used in the game was created specifically for this project.

The cards, buttons, backgrounds, branding, and other graphical elements were **hand-drawn on an iPad** and then integrated into the game using Pygame.

This allowed the project to have its own visual identity rather than relying on pre-made game assets.

## 🚀 Getting Started

### Prerequisites

Make sure you have Python installed on your system.

Install Pygame with:

```bash
pip install pygame
```

### Running the Game

Clone the repository:

```bash
git clone https://github.com/eliasMohamadi/BlackJack.git
```

Navigate into the project:

```bash
cd BlackJack
```

Run the game:

```bash
python src/main.py
```
